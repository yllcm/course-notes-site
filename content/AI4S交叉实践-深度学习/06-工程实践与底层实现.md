## 1. 分类模型的评估指标

### 1.1 精确率、召回率与 F1
- **精确率（Precision）**：预测为正类的样本中，实际为正类的比例。

$$
\text{Precision} = \frac{TP}{TP + FP}
$$

- **召回率（Recall）**：实际为正类的样本中，被成功预测出来的比例。

$$
\text{Recall} = \frac{TP}{TP + FN}
$$

- **F1 度量（F1 score）**：精确率 $P$ 与召回率 $R$ 的调和平均数。

$$
\text{F1} = \frac{2PR}{P + R}
$$

### 1.2 ROC 曲线
ROC 曲线通过滑动分类阈值（threshold）绘制。

- 将样本按模型打分从高到低排序，阈值从高往低滑动。
- **TPR（真正率）** $= \frac{TP}{TP + FN}$（即召回率）。
- **FPR（假正率）** $= \frac{FP}{FP + TN}$。
- 每跨过一个**正样本** → **向上**一步（TPR 增加）。
- 每跨过一个**负样本** → **向右**一步（FPR 增加）。
- 起点 $(0,0)$（不标记任何人），终点 $(1,1)$（标记所有人）。

### 1.3 AUC
- **定义**：ROC 曲线下的面积。
- **统计意义**：随机一个正样本的得分高于随机一个负样本得分的概率。
- **完美模型**：AUC $= 1$；**随机猜测**：AUC $= 0.5$。
- **免疫样本不平衡**：对于随机分类器，患病率在 TPR 和 FPR 中互相抵消，AUC 在任何基础率下恒为 $0.5$。

> [!note]
> 假设筛选占比 $x$ 的人群：$\text{TPR} = \frac{0.01x}{0.01} = x$，$\text{FPR} = \frac{0.99x}{0.99} = x$，患病率被抵消。

## 2. 前向传播

### 2.1 符号约定与维度
| 符号 | 含义 | 维度 |
|---|---|---|
| $N$ | 批次样本数 | — |
| $L$ | 网络总层数 | — |
| $D$ | 输入宽度 | — |
| $C$ | 输出宽度（类别数） | — |
| $\boldsymbol{x}$ | 单个输入 | $\mathbb{R}^D$ |
| $\boldsymbol{y}$ | 单个标签（one-hot） | $\mathbb{R}^C$ |
| $\boldsymbol{X}$ | 输入矩阵（行 = 样本） | $N \times D$ |
| $\boldsymbol{H}^{(l)}$ | 第 $l$ 层激活输出 | $N \times D$ |
| $\boldsymbol{Z}^{(l)}$ | 第 $l$ 层预激活值 | $N \times C$ |
| $\boldsymbol{W}^{(l)}$ | 第 $l$ 层权重矩阵 | $D \times C$ |
| $\boldsymbol{b}^{(l)}$ | 第 $l$ 层偏置向量 | $C$ |
| $\boldsymbol{1}$ | 全 1 列向量（用于偏置广播） | $N$ |

**约定**：小写加粗 $\boldsymbol{x}$ → 向量；大写加粗 $\boldsymbol{X}$ → 矩阵（每行一个样本）；上标 $^{(l)}$ → 层索引。

> **梯度形状守恒**：$\nabla_{\boldsymbol{X}}\mathcal{L}$ 与 $\boldsymbol{X}$ 形状完全相同。

### 2.2 前向传播公式
$$
\boldsymbol{H}^{(0)} = \boldsymbol{X}
$$

$$
\boldsymbol{Z}^{(l+1)} = \boldsymbol{H}^{(l)}\boldsymbol{W}^{(l)} + \boldsymbol{1}\boldsymbol{b}^{(l)\top}
$$

$$
\boldsymbol{H}^{(l)} = g(\boldsymbol{Z}^{(l)})
$$

损失函数（Softmax 交叉熵）：

$$
\begin{align}

\mathcal{L}  & = -\log p(\boldsymbol{Y} \mid \text{softmax}(\boldsymbol{Z}^{(L)})) \\ 
 & = -\log\left( \prod_{j=1}^C \pi_{j}^{y_{j}} \right)\\
 & =- \sum_{j=1}^{C}y_{ij} \log \pi_{ij}
\end{align}

$$

## 3. 反向传播

> 计算损失函数对每一层参数的梯度，从输出层向输入层逐层传递（**backpropagation**）。

### 3.1 符号回顾与前向传播
$$
\boldsymbol{H}^{(0)} = \boldsymbol{X}, \quad
\boldsymbol{Z}^{(l+1)} = \boldsymbol{H}^{(l)}\boldsymbol{W}^{(l)} + \boldsymbol{1}\boldsymbol{b}^{(l)\top}, \quad
\boldsymbol{H}^{(l)} = g(\boldsymbol{Z}^{(l)})
$$

损失函数（Softmax 交叉熵）：

$$
\mathcal{L} = -\log p(\boldsymbol{Y} \mid \text{softmax}(\boldsymbol{Z}^{(L)})) = -\frac{1}{N}\sum_{i,j} Y_{ij} \log H_{ij}
$$




### 3.2 矩阵微分
> **THE TOOLKIT FOR BACKPROP**
>
> Whatever multiplies $\mathrm{d}(\cdot)$ in the differential **is** the gradient.

矩阵微分将求导统一为"从 $\mathrm{d}(\cdot)$ 的系数中直接读出梯度"：

- **Scalar**：$\mathrm{d}y = a\,\mathrm{d}x \;\Rightarrow\; \frac{\mathrm{d}y}{\mathrm{d}x} = a$
- **Vector**：$\mathrm{d}y = \sum_{j} \frac{\partial y}{\partial x_j} \mathrm{d}x_j = \boldsymbol{a}^\top \mathrm{d}\boldsymbol{x}, \quad \boldsymbol{a} = \nabla_{\boldsymbol{x}}y$
- **Matrix**：$\mathrm{d}y = \sum_{i,j} A_{ij} \,\mathrm{d}X_{ij} = \operatorname{tr}(\boldsymbol{A}^\top \mathrm{d}\boldsymbol{X}), \quad \boldsymbol{A} = \nabla_{\boldsymbol{X}}y$

**六个标准形式（six standard forms）：**

| 类型 | 微分形式 | 类型 | 微分形式 |
|---|---|---|---|
| scalar–scalar | $\mathrm{d}y = a\,\mathrm{d}x$ | scalar–vector | $\mathrm{d}y = \boldsymbol{a}^\top \mathrm{d}\boldsymbol{x}$ |
| scalar–matrix | $\mathrm{d}y = \operatorname{tr}(\boldsymbol{A}^\top \mathrm{d}\boldsymbol{X})$ | vector–scalar | $\mathrm{d}\boldsymbol{y} = \boldsymbol{a}\,\mathrm{d}x$ |
| matrix–scalar | $\mathrm{d}\boldsymbol{Y} = \boldsymbol{A}\,\mathrm{d}x$ | vector–vector | $\mathrm{d}\boldsymbol{y} = \boldsymbol{A}\,\mathrm{d}\boldsymbol{x}$ |

**迹函数（Trace）性质：**

$$
\operatorname{tr}(\boldsymbol{A}\boldsymbol{B}) = \operatorname{tr}(\boldsymbol{B}\boldsymbol{A}) \quad (\text{循环移位}), \qquad \operatorname{tr}(\boldsymbol{A}) = \operatorname{tr}(\boldsymbol{A}^\top) \quad (\text{转置不变})
$$

**三步法则（Trace Recipe）：**

1. **Differentiate**：把已知的下游梯度写成 $\mathrm{d}\mathcal{L} = \operatorname{tr}(\boldsymbol{G}^\top \mathrm{d}\boldsymbol{Z})$
2. **Substitute & product-rule**：代入 $\mathrm{d}\boldsymbol{Z}$ 的具体表达式，展开为多项迹的和
3. **Isolate + read off**：用 cyclic/transpose 洗牌，直到 $\mathrm{d}\boldsymbol{X}$ 出现在最右侧，系数即为 $\nabla_{\boldsymbol{X}}\mathcal{L}$



### 3.3 反向传播微分推导
前向传播与损失函数：

$$
\mathbf{Z} = \mathbf{H}\mathbf{W} + \mathbf{1}\mathbf{b}^\top,\quad \mathbf{H} = g(\mathbf{Z}),\quad \mathcal{L} = -\frac{1}{N}\sum_{i,j} Y_{ij} \log H_{ij}
$$

> ⚠️ 注意：求导需区分**输出层（Softmax）**与**隐藏层（逐元素激活函数）**，两者 $\frac{\partial \mathcal{L}}{\partial \mathbf{Z}}$ 的计算方式不同。

---

**输出层：Softmax + 交叉熵（非逐元素）**

由于 Softmax 是向量对向量的映射（每个输出依赖于所有输入），不能使用逐元素的链式法则。但交叉熵与 Softmax 组合后有简洁的封闭形式：

$$
\frac{\partial \mathcal{L}}{\partial \mathbf{Z}^{(L)}} = \frac{1}{N} (\underbrace{\text{softmax}(\mathbf{Z}^{(L)})}_{\mathbf{P}} - \mathbf{Y}) \triangleq \boldsymbol{G}^{(L)}
$$

推导要点（单样本下，省略 $1/N$）：

$$
\frac{\partial \mathcal{L}}{\partial Z_j} = -\sum_k \frac{Y_k}{\pi_k} \cdot \frac{\partial \pi_k}{\partial Z_j},\quad
\frac{\partial \pi_k}{\partial Z_j} = \pi_k(\delta_{kj} - \pi_j)
$$

$$
\Rightarrow \frac{\partial \mathcal{L}}{\partial Z_j} = -\left( Y_j - \pi_j \sum_k Y_k \right) = \pi_j - Y_j
$$

---

**隐藏层：逐元素激活函数（ReLU / Sigmoid）**

激活函数 $g$ 逐元素作用（$H_{ij} = g(Z_{ij})$），可直接用链式法则：

$$
\frac{\partial \mathcal{L}}{\partial Z_{ij}} = \frac{\partial \mathcal{L}}{\partial H_{ij}} \cdot g'(Z_{ij})
$$

矩阵形式（Hadamard 积 $\odot$）：

$$
\mathbf{G}^{(l)} \triangleq \frac{\partial \mathcal{L}}{\partial \mathbf{Z}^{(l)}} = \frac{\partial \mathcal{L}}{\partial \mathbf{H}^{(l)}} \odot g'(\mathbf{Z}^{(l)}) 
$$

> 对于 ReLU：$g'(z) = \mathbf{1}[z > 0]$（即 $Z \ge 0$ 的位置导数为 $1$，否则为 $0$）。

---
^t2hb8r

无论哪一层，一旦得到 $\mathbf{G} = \frac{\partial \mathcal{L}}{\partial \mathbf{Z}}$，对权重和偏置的梯度形式相同。

将 $\mathbf{G}$ 作为已知下游梯度，写出微分：

$$
\mathrm{d}\mathcal{L} = \operatorname{tr}(\mathbf{G}^\top \mathrm{d}\mathbf{Z})
$$

代入前向传播的微分 $\mathrm{d}\boldsymbol{Z} = \boldsymbol{H}\,\mathrm{d}\boldsymbol{W} + \mathrm{d}\boldsymbol{H}\,\boldsymbol{W} + \boldsymbol{1}\,\mathrm{d}\boldsymbol{b}^\top$：

$$
\mathrm{d}\mathcal{L} = \operatorname{tr}(\boldsymbol{G}^\top \boldsymbol{H} \,\mathrm{d}\boldsymbol{W}) + \operatorname{tr}(\boldsymbol{G}^\top \mathrm{d}\boldsymbol{H} \,\boldsymbol{W}) + \operatorname{tr}(\boldsymbol{G}^\top \boldsymbol{1} \,\mathrm{d}\boldsymbol{b}^\top)
$$

三项分别处理，目标是让 $\mathrm{d}(\cdot)$ 出现在最右侧，然后读出系数：

1. **对 $\boldsymbol{W}$**：$\mathrm{d}\boldsymbol{W}$ 已在最右侧，改写为标准形式：
   
   $$
\operatorname{tr}(\boldsymbol{G}^\top \boldsymbol{H} \,\mathrm{d}\boldsymbol{W}) = \operatorname{tr}\big((\boldsymbol{H}^\top \boldsymbol{G})^\top \mathrm{d}\boldsymbol{W}\big) \;\Rightarrow\; \boxed{\nabla_{\boldsymbol{W}}\mathcal{L} = \boldsymbol{H}^\top \boldsymbol{G}}
$$

2. **对 $\boldsymbol{H}$**：循环移位将 $\mathrm{d}\boldsymbol{H}$ 移到最右侧：
   
   $$
\operatorname{tr}(\boldsymbol{G}^\top \mathrm{d}\boldsymbol{H} \,\boldsymbol{W}) \xrightarrow{\text{cyclic}} \operatorname{tr}(\boldsymbol{W}\boldsymbol{G}^\top \mathrm{d}\boldsymbol{H}) = \operatorname{tr}\big((\boldsymbol{G}\boldsymbol{W}^\top)^\top \mathrm{d}\boldsymbol{H}\big) \;\Rightarrow\; \boxed{\nabla_{\boldsymbol{H}}\mathcal{L} = \boldsymbol{G}\boldsymbol{W}^\top}
$$

3. **对 $\boldsymbol{b}$**：转置后凑出内积形式：
   
   $$
\operatorname{tr}(\boldsymbol{G}^\top \boldsymbol{1} \,\mathrm{d}\boldsymbol{b}^\top) = \langle \mathrm{d}\boldsymbol{b}, \boldsymbol{G}^\top \boldsymbol{1} \rangle \;\Rightarrow\; \boxed{\nabla_{\boldsymbol{b}}\mathcal{L} = \boldsymbol{G}^\top \boldsymbol{1}}
$$

汇总：

$$
\boxed{\nabla_{\boldsymbol{W}}\mathcal{L} = \boldsymbol{H}^\top \boldsymbol{G},\quad \nabla_{\boldsymbol{H}}\mathcal{L} = \boldsymbol{G}\boldsymbol{W}^\top,\quad \nabla_{\boldsymbol{b}}\mathcal{L} = \boldsymbol{G}^\top \boldsymbol{1}}
$$

---

**递归：**

$\nabla_{\boldsymbol{H}}\mathcal{L} = \boldsymbol{G}\boldsymbol{W}^\top$ 作为上一层的下游梯度（即该层的 $\frac{\partial \mathcal{L}}{\partial \mathbf{H}^{(l-1)}}$），代入 $\boldsymbol{G}^{(l)} = \nabla_{\mathbf{H}^{(l)}}\mathcal{L} \odot g'(\mathbf{Z}^{(l)})$ 计算出该层的 $\boldsymbol{G}^{(l-1)}$，递归得到每一层的梯度：

$$
\boldsymbol{G}^{(L)} = \frac{\mathbf{P} - \mathbf{Y}}{N} \quad\longrightarrow\quad
\nabla_{\boldsymbol{W}^{(L)}}\mathcal{L},\; \nabla_{\boldsymbol{b}^{(L)}}\mathcal{L},\; \nabla_{\boldsymbol{H}^{(L-1)}}\mathcal{L}
$$

$$
\nabla_{\boldsymbol{H}^{(L-1)}}\mathcal{L} \;\xrightarrow{\boldsymbol{G}^{(l)}}\; \boldsymbol{G}^{(L-1)} \quad\longrightarrow\quad
\nabla_{\boldsymbol{W}^{(L-1)}}\mathcal{L},\; \nabla_{\boldsymbol{b}^{(L-1)}}\mathcal{L},\; \nabla_{\boldsymbol{H}^{(L-2)}}\mathcal{L}
$$

$$
\vdots
$$

直至输入层。此即反向传播的完整流程。

## 4. PyTorch 基础

### 4.1 Tensor 的创建
PyTorch 基本对象：`torch.tensor()`

```python
torch.tensor([1, 2, 3])             # 从列表创建
torch.zeros(3, 4)                    # 全 0 矩阵
torch.ones(3, 4)                     # 全 1 矩阵
torch.eye(3)                         # 单位矩阵
torch.empty(3, 4)                    # 未初始化（垃圾值，速度最快）
torch.full((3, 4), 2.0)              # 全部填充为 2.0
torch.rand(3, 4)                     # 均匀分布 [0,1)

torch.randint(0, 10, size=(3, 4))    # 随机整数 [0, 10)

# 按已有张量形状创建
torch.zeros_like(x)                  # 与 x 形状相同的全 0 矩阵
torch.ones_like(x)                   # 与 x 形状相同的全 1 矩阵
torch.randn_like(x)                  # 与 x 形状相同的正态随机矩阵
```

**shape 约定**：`{}` 为标量，`{4,}` 为 4 维向量，`{3, 4}` 为 $3 \times 4$ 矩阵。

### 4.2 基本运算与类型转换

> 例：`a.max(dim=1)` 对每行取最大值 → 形状从 `(N, D)` 变为 `(N,)`。

**实用组合——计算分类准确率：**

```python
# 模型输出 P: (N, C)，标签 Y: (N,)
pred = P.argmax(dim=1)                     # 预测类别

acc = correct / len(Y)                     # 准确率
```

### 4.4 广播机制（Broadcasting）
维度更低的数组在前面补 $1$，然后对齐各维度——每个维度的长度要么相等，要么为 $1$。

| 左形状 | 右形状 | 结果 |
|---|---|---|
| `(2, 3)` | `(3,)` → 变为 `(1, 3)` | `(2, 3)` |
| `(2, 3, 4)` | `(1, 4)` → 变为 `(1, 1, 4)` | `(2, 3, 4)` |
| `(3, 4)` | `(2, 4)` | ❌ 不能加（$3 \neq 2$ 且没有一个是 $1$） |

```python
# 广播的实际例子：归一化
x = torch.randn(64, 3, 32, 32)   # (N, C, H, W)
mean = x.mean(dim=(0, 2, 3))     # 对 N, H, W 求均值，剩下 (C,)
x_norm = x - mean                # → 广播：(64,3,32,32) - (3,) ✓
```

### 4.5 GPU 与硬件概念
- **FLOPS**：每秒浮点运算次数（Floating Point Operations Per Second）。
- **Tensor Core**：专为矩阵乘法加速的硬件单元。
- **显存带宽**：在内存和计算核心之间传输数据的效率。

以 RTX 5090 为例：170 个 SM $\times$ 4 个 Tensor Core $\times$ 128 FLOP/cycle。

**GPU 使用检查：**

## 5. 自动求导与训练

### 5.1 计算图与 Autograd
PyTorch 通过**计算图**实现自动求导：

- 计算图是一个 **DAG（有向无环图）**，节点是算符（如 `+`, `@`, `exp`），边是数据流（张量）。
- **叶子节点**：`requires_grad=True` 的张量（通常是模型参数或输入）。
- **非叶子节点**：中间计算结果，记录 `grad_fn` 指向其产生方式。
- `.backward()`：从损失出发，**反向拓扑排序**遍历计算图，自动计算所有叶子节点的梯度。
- 每次 `.backward()` 后计算图被**销毁并重建**（动态图机制）。

```python
x = torch.tensor([1.0], requires_grad=True)   # 开启梯度追踪
y = x ** 2
y.backward()          # 自动求导（dy/dx = 2x = 2.0）
print(x.grad)         # 访问梯度 → tensor([2.0])

# 查看非叶子节点的 grad_fn
print(y.grad_fn)      # <PowBackward0 object>
```

**梯度累加：**

```python
x = torch.tensor([1.0], requires_grad=True)
loss = (x ** 2).sum()
loss.backward()
print(x.grad)         # tensor([2.0])

loss = (x ** 2).sum() # 第二次 forward
loss.backward()       # 梯度***累加***到 .grad 上
print(x.grad)         # tensor([4.0]) ← 不是 2.0！
```

> 所以每个训练步之前必须 **`opt.zero_grad()`**（或用 `x.grad.zero_()`），否则梯度会跨步累加。

**关掉自动求导：**

```python
with torch.no_grad():       # 上下文管理器，内部运算不建图
    ...                     # 用于推理，节省显存和计算

x.detach()                  # 返回新张量，断开与计算图的连接
```

> 典型场景：**推理（inference）** 和 **特征提取** 时不需要梯度。

### 5.2 自定义 Function
通过继承 `torch.autograd.Function` 自定义前向与反向传播：

```python
class Exp(Function):
    @staticmethod
    def forward(ctx, x):
        y = x.exp()
        ctx.save_for_backward(y)      # 保存供 backward 使用的值
        return y

    @staticmethod
    def backward(ctx, gy):
        y, = ctx.saved_tensors
        return gy * y                 # d(exp(x))/dx = exp(x)
```

**完整训练循环——手动梯度：**

```python
for step in range(steps):
    # forward pass
    Z1 = X @ W1 + b1
    H1 = torch.relu(Z1)
    Z2 = H1 @ W2 + b2
    P = torch.softmax(Z2, dim=1)
    loss = -(Y * P.log()).sum() / N

    # backward pass (手动实现梯度，对应 14.3 节公式)
    G2 = (P - Y) / N                     # ∇ Z2
    dW2 = H1.T @ G2                      # ∇ W2 = H^T G
    db2 = G2.sum(0)                      # ∇ b2 = G^T 1
    dH1 = G2 @ W2.T                      # ∇ H1 = G W^T
    G1 = (Z1 >= 0) * dH1                 # ∇ Z1 (ReLU: g'(z) = 1[z>0])
    dW1 = X.T @ G1                       # ∇ W1
    db1 = G1.sum(0)                      # ∇ b1

    # SGD update
    W1 -= lr * dW1;  b1 -= lr * db1
    W2 -= lr * dW2;  b2 -= lr * db2
```

```python
    def forward(self, X):

model = Net(D=784, Hd=256, C=10)
```

```python
def evaluate(model, loader, device='cpu'):
    model.eval()                         # ← 必须切换！
    correct = 0
    total = 0
    with torch.no_grad():                # ← 必须关闭梯度！
        for X, Y in loader:
            X, Y = X.to(device), Y.to(device)
            out = model(X)               # (N, C)
            pred = out.argmax(dim=1)     # (N,)
            correct += torch.eq(pred, Y).sum().item()
            total += len(Y)
    return correct / total
```

## 6. 分布式并行

### 6.1 数据并行（Data Parallelism）

每个 worker 持有完整模型副本，处理数据分片，通过 **All-Reduce** 同步梯度：

$$
g(w, \xi) = \frac{1}{m} \sum_{i=1}^m \nabla_w f_i(w)
$$

等价于在单机上处理整个大 batch，PyTorch 的 `DistributedDataParallel` 实现了此机制。

### 6.2 流水线并行（Pipeline Parallelism）

将模型的不同层分布在不同设备上，并将 mini-batch 拆分为微批次（microbatches）以减少设备空闲时间（"bubble"）。
