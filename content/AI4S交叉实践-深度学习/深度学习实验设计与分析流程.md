# 深度学习实验设计与分析流程

> 从课程实验中总结的系统化实验方法。


## 1. 实验设计原则

### 1.1 明确基线（Baseline）

在开始任何训练前，先确定：
- **核心指标**：分类用 Accuracy / F1，回归用 MSE
- **基线模型**：最简单的模型作为对照组，所有改进与之对比

### 1.2 控制变量

科学实验的核心：每次只改变一个变量。

| 变量类型 | 示例 | 说明 |
|---------|------|------|
| **自变量**（你想变的） | lr、batchsize、width、depth | 每次只变一个 |
| **因变量**（你观察的） | loss、accuracy | 训练后记录 |
| **控制变量**（固定不变的） | 随机种子、数据集划分、优化器 | 确保可复现 |

> **变量耦合**：同时改变多个超参数时，你不知道 Acc 的变化是哪个参数引起的。

### 1.3 消融实验（Ablation Study）

同时引入多个改进时，通过逐一移除某个模块来证明其有效性。


## 2. 实验执行流程

### 2.1 分阶段推进

第一阶段：预实验 —— 确定核心参数的合理范围

> 固定大部分变量，扫描单个参数。例如固定 depth=2, batchsize=64, width=512，扫 lr=[0.05, 0.1, 0.2, 0.35, 0.5]，找到最优 lr 区间。

第二阶段：主实验 —— 系统探索

> 固定已确定的范围，改变关心的参数。例如固定 batchsize=64, depth=2，变 width × lr。

第三阶段：拓展实验 —— 验证其他维度

> 加入 depth、batchsize 等额外维度。

### 2.2 超参数网格设置

```python
# 建议的 lr 梯度
lr_list = [0.001, 0.01, 0.05, 0.1, 0.2, 0.35, 0.5]

# 建议的 batchsize 梯度
bs_list = [32, 64, 128, 192, 256, 384, 512]

# 建议的 width 梯度
width_list = [64, 128, 256, 512]
```

> lr 按对数尺度（倍数变化）设置，batchsize 按 2 的幂或线性设置。


## 3. 数据管理

### 3.1 自动记录实验数据

训练脚本应自动记录所有指标到 CSV，不要手动复制粘贴终端输出：

```python
# 每跑完一组实验，自动追加一行记录
import csv
from datetime import datetime

info = {
    'timestamp': datetime.now().strftime('%Y-%m-%d %H:%M'),
    'width': width, 'depth': depth,
    'lr': lr, 'batchsize': batchsize,
    'test_loss': test_loss,
    'test_acc': test_acc,
    'notes': '',      # 文字说明，如"大批量下 acc 下降，怀疑泛化鸿沟"
}

with open('experiment_data_all.csv', 'a', newline='') as f:
    csv.DictWriter(f, fieldnames=info.keys()).writerow(info)
```

这样一次训练就能同时记录 loss 和 acc，不需要事后补跑。时间戳可追溯实验顺序，备注列用于记录实验中的异常现象或特殊处理。

### 3.2 Log 文件记录

使用 Python `logging` 模块同时在终端输出和写入 log 文件：

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s | %(message)s',
    handlers=[
        logging.FileHandler(f'Exp_{ts}_w{width}_lr{lr}/train.log'),
        logging.StreamHandler()
    ]
)

logging.info(f'Start training | width={width}, depth={depth}, lr={lr}')

for epoch in range(epochs):
    train_loss, train_acc = ...
    logging.info(f'Epoch {epoch:3d} | train_loss={train_loss:.4f} | train_acc={train_acc:.4f}')

logging.info(f'Done | test_loss={test_loss:.4f} | test_acc={test_acc:.4f}')
```

log 文件记录了训练全过程的每步指标和时间戳，用于事后排查训练过程中的异常（如 loss 突然炸了、某 epoch 后 acc 骤降），与仅保存最终结果的 CSV 互为补充。

### 3.3 CSV 统一格式

建议的列名标准：

```
batchsize, width, depth, lr, test_acc, test_loss
```

每行一个实验配置，不要手动拆分合并。

### 3.3 实验记录表结构

```
timestamp | 模型参数 | 超参数 | 训练指标 | 测试指标 | 备注
```

- **timestamp**：时间戳，如 `2026-07-14 14:30`，自动记录实验时间，用于追溯顺序
- **模型参数**：Width, Depth
- **超参数**：Learning Rate, Batch Size
- **测试指标**：Test Loss, Test Accuracy
- **备注**：文字说明，如实验结果异常的原因或特殊处理

## 4. 数据分析与可视化

### 4.1 先画图，不要看数字

100 多组数字放在表格里看不出趋势，画成曲线图后一眼就能看出波峰位置和漂移方向。

**画图是最省时间的分析方法。**

### 4.2 学习曲线分析

| 现象 | 判断 | 对策 |
|------|------|------|
| 训练和验证 Loss 都很高 | 欠拟合 | 增加模型复杂度，延长训练 |
| 训练 Loss 降，验证 Loss 升 | 过拟合 | 正则化（Dropout, Weight Decay）|
| 两者同步下降并饱和 | 正常收敛 | — |

### 4.3 lr 分析的画图方法

```python
# 固定 batchsize=64, depth=2，变 width + lr
data = df[(df['batchsize'] == 64) & (df['depth'] == 2)]

plt.figure(figsize=(8, 5))
for w in [128, 256, 512]:
    subset = data[data['width'] == w].sort_values('lr')
    plt.plot(subset['lr'], subset['test_acc'], 'o-', label=f'w={w}')

plt.xscale('log')     # lr 必须用对数坐标
plt.xlabel('Learning Rate')
plt.ylabel('Test Accuracy')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### 4.4 batchsize 分析的画图方法

```python
# 固定 lr=0.1, depth=2，变 width + batchsize
data = df[(df['lr'] == 0.1) & (df['depth'] == 2)]

plt.figure(figsize=(8, 5))
for w in [128, 256, 512]:
    subset = data[data['width'] == w].sort_values('batchsize')
    plt.plot(subset['batchsize'], subset['test_acc'], 'o-', label=f'w={w}')

plt.xlabel('Batch Size')
plt.ylabel('Test Accuracy')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

### 4.5 坐标系选择规则

| 横坐标 | 是否取对数 | 原因 |
|--------|-----------|------|
| Learning Rate | **必须**（`plt.xscale('log')`）| 倍数变化，对数轴均匀拉伸 |
| Batch Size | 一般不用 | 线性或 2 的幂次变化 |
| Epoch | 不用 | — |

### 4.6 Loss 与 Acc 的配合

- **loss 最低点 ≠ acc 最高点**。大批量倾向于收敛到尖锐极小值，测试集上 acc 反而低（大批量泛化鸿沟）。
- Loss 曲线在分析 batchsize 趋势时比 Acc 更清晰（V 形谷底更明显）。
- 两者互为印证，同时记录。


## 5. 常见问题与对策

### 5.1 变量耦合

**症状**：跑了 50+ 组实验但看不出趋势。
**原因**：同时改变了多个超参数。
**对策**：控制变量，每次只变一个参数，分组画图。

### 5.2 小模型（width=64）的 batchsize 曲线震荡

**症状**：width=64 的 loss 随 batchsize 变化无规律震荡。
**原因**：模型太小，对梯度噪声极度敏感。
**对策**：batchsize 分析中剔除 width=64，只保留 128/256/512。

### 5.3 大批量下 acc 下降

**症状**：batchsize 增大时 loss 降低但 acc 下降。
**原因**：大批量泛化鸿沟（Generalization Gap）——大 batch 倾向于尖锐极小值。
**对策**：以 acc 为主要指标，或使用小 batch 的正则化效果。

## 7. 总结

1. **控制变量**：每次只变一个超参数
2. **先画图**：画图是最省时间的分析方法
3. **分阶段推进**：预实验 → 主实验 → 拓展实验
4. **自动化记录**：不要手动复制终端输出
5. **Loss 和 Acc 都要记**：两者互相印证
6. **lr 用对数坐标**：倍数变化的数据必须 log
